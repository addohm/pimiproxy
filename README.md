📦 pimiproxy v1.7pimiproxy is a containerized, user-friendly "Sidecar" Proxy for Raspberry Pi. It turns your Pi into a dedicated network service that allows devices (like the Meta Quest, smartphones, and consoles) to use a proxy without needing to reconfigure your main router or risk breaking your home internet.✨ FeaturesZero-Config Discovery: Uses mDNS (Avahi) so you can connect via pimiproxy.local instead of hunting for IP addresses.Express Installation: Get up and running in seconds with smart defaults.Global Reliability: Specialized --china-mirror mode for users in Mainland China to bypass Docker repository blocks.Modular Architecture: Runs the Mihomo (Clash Meta) engine and a modern Web Dashboard in separate, lightweight containers.Surgical Uninstaller: Records your system's original state (hostname, Docker status) and restores it perfectly upon removal.🚀 InstallationEnsure you are on a fresh installation of Raspberry Pi OS Lite (or any Debian-based system).Option 1: Express Mode (Recommended)This mode accepts all defaults (Host: pimiproxy.local, Proxy Port: 7890, Dashboard Port: 8080).Bashsudo ./install.sh
# Select Option 1 (Express) when prompted
Option 2: China Mirror ModeIf you are installing from Mainland China, use this flag to automatically enable Aliyun mirrors and registry optimizations:Bashsudo ./install.sh --china-mirror
Option 3: Manual ModeCustomize your installation directory, hostname, and specific network ports:Bashsudo ./install.sh
# Select Option 2 (Manual) when prompted

Some older Windows/Android versions may require a static IP instead.Dashboard "Disconnected": This usually means the API port (default 9292) is blocked or the Mihomo engine failed to start due to a config error.
